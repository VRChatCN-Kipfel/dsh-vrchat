fix: the docs described a plugin that was never built, and the numbers had no guard

Three things, all of the same shape: an artifact that looked maintained and was not.

DOCS. docs/vrchat-kb-architecture.md still said "正式代码尚未落地" while the plugin
had been installed and running for two weeks. Worse, its §2/§4 described a design
that was abandoned: seven lib modules (content/blocks/inject/agentScope/gate/tool)
that never existed, four runtime flows built on agent/pre-step and
tools/post-execute, none of which are registered anywhere. Someone reading it would
have gone looking for files that are not there. Rewritten against the installed
0.29.0 — the numbers in it (10,835 / 7,964 / 551 characters) are read back from the
built patch, not remembered.

The abandoned design is preserved in §11 rather than deleted, with the reasoning:
AssembleContext carries no agent and no messages, so per-turn conditional injection
was never available through systemPrompt.section, and the vocabulary gate it needed
disappeared the moment the default tier stopped injecting anything at all.

README said "6 个工具"; there are 8.

NUMBER PROVENANCE. Every other guard checks shape or structure. None checked the
plugin's own promise — that these are tested conclusions, not general advice. A
digit is invisible to all of them: change 70,000 to 75,000 in the persona and 60+
checks stay green. number-provenance-check ties each guarded number back to a corpus
page, and its selftest proves it fails on drift rather than merely printing PASS.

Written honestly, which took three revisions: a unit-bearing number must match with
its unit (searching "15" hits immediately in 414 pages), a thousands-separated one
matches on digits alone, and neither counts unless it co-occurs with a topic word
from the same persona line IN THE SAME PAGE.

One limit is asserted rather than hidden: 256 bits -> 128 bits passes, because
expression-menu.md:434 really does say "256 bits（约 128 bits 老 SDK）". The guard
checks that a number exists under a topic; it does not read the qualifying clause
around it. That case is a PASS on the limit, with a note saying what to do if it
ever starts failing.

TWO INSTANCES DOING ONE JOB. `vrchat-skills` kept the default includeDefaultRoots,
so it scanned ~/.agents/skills and the project roots as well — the same roots the
standard `skill-filesystem` row already serves. Both providers returned the same
eight user skills, the registry dropped the duplicates and logged a warning each
time, and every scan paid twice for an identical answer. Now false: five skills,
all source=custom.

PATHS. Four tools plus two probes hardcoded the DSH install directory. That is the
same mistake build-preset-plugins.mjs had already been fixed for, so the known-good
derivation moved into lib-host-modules.cjs and all six now share it. The failure
message lists the distinct anchor kinds rather than 22 absolute paths.
